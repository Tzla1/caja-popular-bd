Una base, tres motores:
PostgreSQL traducida a MariaDB y Oracle

PostgreSQL · origen → MariaDB 12.3 + Oracle Free 23ai Cargada y verificada en ambos

El esquema original (11 tablas, restricciones CHECK con regex, 7 funciones plpgsql con triggers, 3 vistas, roles y datos semilla con orden crítico) se tradujo a los dialectos de MariaDB y Oracle conservando todas las reglas de negocio. Los conteos coinciden fila por fila y cada restricción rechaza los datos inválidos en los dos motores.

04 Cómo probarlo en clase

Cada motor se levanta con un solo comando. Los scripts numerados corren en orden.

MariaDB

# ya instalado en el equipo
cd MariaDB
./run_all.sh

# entrar a consultar
sudo mariadb BD_Jesdreel_Daniel_Mata_Gomez

Oracle (Docker)

# levanta Oracle Free en contenedor
cd Oracle
./run_all.sh

# entrar a consultar
docker exec -it oracle-caja \
  sqlplus caja/Caja_2026@localhost:1521/FREEPDB1

Orden de los scripts Oracle: 0_Crear_Usuario → 1_Estructura → 2_Logica_Reglas → 3_Datos → 4_Logica_Movimiento → 5_Roles_Permisos. El orden importa: las reglas se crean antes de los datos (validan la carga) y la lógica de movimiento después, para no recalcular los saldos semilla — exactamente como el original.

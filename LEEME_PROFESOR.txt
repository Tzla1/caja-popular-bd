===============================================================
INSTALACION RAPIDA (3 pasos)
===============================================================

Paso 1: Abrir pgAdmin y conectarse al servidor de PostgreSQL.

Paso 2: Este script (1_Crear_Base_Datos.txt) trae DROP DATABASE y
        CREATE DATABASE, y PostgreSQL no permite ejecutar esas dos
        instrucciones junto con otras en un solo Query Tool normal
        (da error "cannot run inside a transaction block"). Por eso
        se usa la herramienta PSQL Tool de pgAdmin en vez del Query
        Tool: ahi si se puede pegar el script completo y correrlo
        de una sola vez.

        1. En el arbol de la izquierda, dar clic sobre el servidor
           de PostgreSQL (o sobre la base "postgres").
        2. Menu superior Tools -> PSQL Tool. Se abre una pestana
           tipo terminal. Si pide contrasena, escribir la del
           usuario postgres.
        3. Abrir 1_Crear_Base_Datos.txt con el Bloc de notas,
           Ctrl+A, Ctrl+C, y pegar todo dentro de esa terminal
           (clic derecho -> Paste, o Ctrl+Shift+V). Presionar Enter.
        4. Van a aparecer los mensajes DROP DATABASE, CREATE DATABASE
           y COMMENT uno tras otro, todo en un solo pegado.

        Refrescar Databases (clic derecho -> Refresh) en el arbol
        de la izquierda: aparece "BD_Jesdreel_Daniel_Mata_Gomez".

Paso 3: Clic derecho sobre "BD_Jesdreel_Daniel_Mata_Gomez"
        -> Query Tool. Abrir 2_Estructura_y_Datos.txt con el
        Bloc de notas, Ctrl+A, Ctrl+C, pegar en el Query Tool
        y presionar F5. Listo.

===============================================================
VERIFICACION
===============================================================

Ejecutar en el Query Tool de la nueva base:

    SELECT 'Sucursales' AS tabla, COUNT(*) FROM sucursales
    UNION ALL SELECT 'Empleados',        COUNT(*) FROM empleados
    UNION ALL SELECT 'Socios',           COUNT(*) FROM socios
    UNION ALL SELECT 'Documentos',       COUNT(*) FROM documentos_socio
    UNION ALL SELECT 'Beneficiarios',    COUNT(*) FROM beneficiarios
    UNION ALL SELECT 'Cuentas ahorro',   COUNT(*) FROM cuentas_ahorro
    UNION ALL SELECT 'Prestamos',        COUNT(*) FROM prestamos
    UNION ALL SELECT 'Transacciones',    COUNT(*) FROM transacciones
    UNION ALL SELECT 'Abonos prestamo',  COUNT(*) FROM abonos_prestamo;

Debe mostrar: 6, 14, 30, 240, 52, 30, 18, 80, 15.
